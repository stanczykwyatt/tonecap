# Changelog

## 0.1.0 (2026-11-25)

First release.

- **A sound engine with no recordings:** switch type, spring, lube, bottom-out and top-out; plate, case and foam; keycap material, thickness and profile; stabilizers. Wide keys sound deeper, keys are placed left to right, and every press varies a little.
- **A web playground** with sliders and presets, a test box, a sample line, A/B comparison, WAV export, and the whole build in a shareable link.
- **A Mac menu bar app** that plays the sound as you type in any app, with the same settings in a dark panel, link import, volume, ⌃⌥M to mute and per-app mute.
- **The engine in JavaScript and Swift,** tested to render the same samples.
- Input Monitoring as the app's only permission: key codes only, listen-only, no entitlements, no network access.
